# Supabase

Carpeta reservada para las migraciones SQL y la configuración del proyecto Supabase
(tablas `perfiles`, `solicitudes_permiso`, `notificaciones`, `registros_acceso`,
políticas de Row Level Security, Storage para fotos de perfil, etc.).

Se completa en la siguiente fase, junto con la generación de tipos TypeScript
desde el esquema real (`supabase gen types typescript`).
